# SecureDocs

SecureDocs es una aplicación web académica para gestionar documentos empresariales con autorización en dos etapas: RBAC determina si el rol posee el permiso base y ABAC valida si el acceso es válido bajo las condiciones del usuario, el recurso y el entorno.

> El proyecto se encuentra en construcción. Las instrucciones completas, usuarios de demostración, diagramas y evidencias se incorporan en los siguientes commits.
